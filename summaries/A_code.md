This appendix is an index of the short Python programs behind every figure and numerical statement in the book. For each program it gives a one line purpose and the chapters and figures that use it. The programs live in the public repository of the book, to be archived with a DOI at release, and are run from the code directory or from the book root. It covers heat bath and Monte Carlo simulation of lattice gauge theory, the Migdal Kadanoff ladder, heat kernel computations, torus zero counts and the figure scripts.
